# وتواصوا بالحق · سلسلة صفة الكفر بالطاغوت

موقع السلسلة بالعربية والتركية: https://muhammet199500.github.io/khareeta/

## محتويات الموقع

| الصفحة | العربية | التركية |
|---|---|---|
| الصفحة الرئيسية | `index.html` | `tr/index.html` |
| الخريطة التفاعلية | `map.html` | `tr/map.html` |
| صفحة الدرس | `l1/index.html` · `l2/index.html` | `tr/l1/` · `tr/l2/` |
| الدرس المكتوب | `l1/text.html` · `l2/text.html` | `tr/l1/text.html` · `tr/l2/text.html` |
| عرض الشرائح | `lN/slides.html` | `tr/lN/slides.html` |
| أسئلة وأجوبة | `lN/qa.html` | `tr/lN/qa.html` |
| الاختبار | `lN/quiz.html` | `tr/lN/quiz.html` |

بيانات الخريطة والاختبار في `data.js` و`tr/data_tr.js`.
الروابط القديمة مثل `/khareeta/#l2` تُحوَّل تلقائيًا إلى الخريطة.

## قاعدة الموقع

كل ما يُضاف بالعربية يُضاف مثله بالتركية في `tr/`.

## الخطوط

الخطوط محفوظة داخل الموقع في `assets/fonts/` (رخصة SIL المفتوحة)، فلا يعتمد الموقع على Google Fonts:
Reem Kufi للعناوين العربية، وIBM Plex Sans Arabic للأزرار والأسئلة، وNoto Naskh Arabic للقراءة، وAmiri Quran للآيات، وAmiri للنصوص المنقولة؛
وEB Garamond وSource Sans 3 للتركية.

## رفع الفيديوهات

ارفع الملفات إلى مجلد `media/` بهذه الأسماء بالضبط، وستظهر في الموقع تلقائيًا:

| الملف | مكانه |
|---|---|
| `teaser-ar.mp4` | التشويقة في الصفحة الرئيسية العربية |
| `teaser-tr.mp4` | التشويقة في الصفحة الرئيسية التركية |
| `lesson1.mp4` | فيديو الدرس الأول بالعربية |
| `lesson1-tr.mp4` | فيديو الدرس الأول بالتركية |
| `lesson2.mp4` | فيديو الدرس الثاني بالعربية |
| `lesson2-tr.mp4` | فيديو الدرس الثاني بالتركية |

ما دام الملف غير مرفوع تظهر مكانه عبارة «يُضاف قريبًا».

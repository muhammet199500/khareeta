# وتواصوا بالحق · سلسلة صفة الكفر بالطاغوت

موقع السلسلة بالعربية والتركية: https://muhammet199500.github.io/khareeta/

## ترتيب المستودع

| المجلد | ما فيه |
|---|---|
| `src/` | **ملفات المصدر.** منها يُبنى الموقع، وفيها يكون كل تعديل. لا تُنشر للناس. |
| `docs/` | **الموقع الجاهز** الذي ينشره GitHub Pages. يُولَّد من `src/`، فلا يُعدَّل يدويًا (عدا رفع الفيديوهات). |

داخل `src/`:

| المسار | ما فيه |
|---|---|
| `content/lessonN-ar.md` و`lessonN-tr.md` | الدرس المكتوب بالعربية والتركية |
| `decks/ar1` `tr1` `ar2` `tr2` | الشرائح: ترتيبها في `deck.json`، وكل شريحة ملف في `slides/` |
| `maps/map-ar.html` `map-tr.html` | صفحتا الخريطة التفاعلية |
| `maps/data.js` `data_tr.js` | فروع الخريطة وأسئلة الاختبار والعبارة الجامعة لكل درس |
| `build.py` | برنامج البناء، وفيه بيانات الدروس ونصوص الواجهة باللغتين وأسئلة الدرس المكتوب العربية |
| `docqa_tr.py` | أسئلة الدرس المكتوب وأجوبتها بالتركية |
| `summaries.py` | محتوى الملخص المطبوع لكل درس |
| `assets/` | التصميم (CSS) والبرامج (JS) والخطوط |
| `media/` | الشعار والصور وملفات الملخص (PDF وJPG) |
| `tools/` | أدوات الفحص وتوليد ملفات الملخص |

## بناء الموقع

يحتاج Python 3.9 أو أحدث:

```
pip install markdown segno
python3 src/build.py
```

فيُكتب الموقع كاملًا في `docs/`. ثم يُرفع التغيير (commit وpush) فيظهر خلال دقائق.

**بعد تعديل محتوى ملخص** (`summaries.py`) تُولَّد ملفات PDF والصور من جديد:

```
pip install playwright opencv-python && playwright install chromium
python3 -m http.server 8765 --directory docs &
python3 src/tools/gen_summary.py http://localhost:8765/
python3 src/build.py
```

**الفحص قبل الرفع:** `python3 src/tools/test.py http://localhost:8765/` يفتح كل صفحة بمقاس الهاتف والحاسوب، ويبلّغ عن الأخطاء والروابط المعطّلة.

**صور المشاركة** (`share-lN-LANG.jpg`): بعد تعديل عنوان درس أو آيته تُولَّد من جديد بـ `python3 src/tools/gen_share.py http://localhost:8765/` ثم `python3 src/build.py`.

## ميزات للطالب

- **تطبيق يعمل بلا إنترنت:** `sw.js` و`manifest.webmanifest` يولّدهما البناء تلقائيًا. الصفحات تُجلب من الشبكة أولًا، فيصل كل تعديل للطلاب متى اتصلوا، وتُحفظ نسخة تُفتح عند انقطاع الإنترنت (الفيديوهات لا تُحفظ لحجمها).
- **متابعة التقدّم:** تُحفظ على جهاز الطالب وحده (لا حسابات ولا إرسال بيانات). الطالب نفسه يضغط «أنهيتُ…» في آخر كل أداة (الدرس المكتوب، الشرائح، الخريطة، الأسئلة، الاختبار) وفي صفحة الدرس ليسجّل أنه أتمّه، ويضغط مرة أخرى للتراجع. وأفضل نتيجة في الاختبار تُحفظ تلقائيًا.
- **تكبير الخط** في الدرس المكتوب والأسئلة والأجوبة، ويُحفظ اختيار الطالب.

## نقطة الرجوع

الفرع `nuskha-1` يحفظ الموقع كما كان قبل هذه الميزات. للرجوع إليه يُنشر محتواه بدل `main`.

## إضافة درس جديد

1. الدرس المكتوب: `src/content/lesson3-ar.md` و`lesson3-tr.md`.
2. الشرائح: `src/decks/ar3` و`tr3`، بنفس ترتيب المجلدات الموجودة. وتكون أسئلة المراجعة في شرائح يبدأ اسمها بـ`review`.
3. الخريطة والاختبار: إضافة الدرس إلى `src/maps/data.js` و`data_tr.js`.
4. في `src/build.py`: جعل الدرس `live=True` في قائمة `LESSONS` مع وصفه وآيته وأسماء مجلدات شرائحه، وإضافة أسئلة الدرس المكتوب إلى `DOCQA`، وإضافة نظيرها التركي في `docqa_tr.py`.
5. الملخص: إضافة الدرس إلى `summaries.py` باللغتين، ثم توليد ملفاته كما سبق.
6. البناء والفحص والرفع.

## الخطوط

الخطوط محفوظة داخل الموقع في `assets/fonts/` (رخصة SIL المفتوحة)، فلا يعتمد الموقع على Google Fonts:
Reem Kufi للعناوين العربية، وIBM Plex Sans Arabic للأزرار والأسئلة، وNoto Naskh Arabic للقراءة، وAmiri Quran للآيات، وAmiri للنصوص المنقولة؛ وEB Garamond وSource Sans 3 للتركية.

## رفع الفيديوهات

ارفع الملفات إلى مجلد `docs/media/` بهذه الأسماء بالضبط، وستظهر في الموقع تلقائيًا (البناء لا يحذف ما في هذا المجلد):

| الملف | مكانه |
|---|---|
| `teaser.mp4` | التشويقة في الصفحتين الرئيسيتين (مرفوعة، وهي بالعربية والتركية معًا) |
| `lesson1.mp4` | فيديو الدرس الأول بالعربية |
| `lesson1-tr.mp4` | فيديو الدرس الأول بالتركية |
| `lesson2.mp4` | فيديو الدرس الثاني بالعربية |
| `lesson2-tr.mp4` | فيديو الدرس الثاني بالتركية |

ما دام الملف غير مرفوع تظهر مكانه عبارة «يُضاف قريبًا».

الروابط القديمة مثل `/khareeta/#l2` تُحوَّل تلقائيًا إلى الخريطة.
